02 · Projects index — design rationale

  1. Borrowed: Hosachiguru's project pages use full-bleed alternating photo/info bands with restrained editorial type; the quiet "coming" entry mirrors their project-list restraint. The oversized ghost numerals are our typographic signature device (also on 01/03).
  2. Adapted: instead of Hosachiguru's farm-imagery, each row is anchored by the real VSS signboard photo (proof, not mood); specs live in a compact 2×2 fact table (extent / plots / plot size / price) with every client-unconfirmed figure asterisked; availability for Landmark City is a real 24-dot plot-state strip, not an invented marketing claim.
  3. Improves on the previous proposal: the old grid of identical cards read as a catalogue. Alternating full-width rows create a rhythm of image→text→image; the quiet OMR row (dashed, dimmed render, "nothing is offered until then") turns a missing project into a credibility statement. The typographic hero + full-width aerial strip gives the page an opening moment instead of jumping straight into listings.
  4. Client to supply: confirmed extents, plot counts, size ranges, prices & availability counts per project; DTCP approval numbers (visible on signboard photos but unconfirmed); OMR project status/extent; location naming (Thiruppalai Nadu*); a wide landscape photo per project if hero-grade imagery is wanted on rows.
