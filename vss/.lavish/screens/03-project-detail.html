03 · Project detail — design rationale

  1. Borrowed: Kendrick Guehr's persistent background — the hero image stays fixed while opaque content bands slide over it, with one transparent "reveal" gap mid-page; Hosachiguru's project page rhythm — full-width hero with the property name layered over it, then relaxed editorial sections; Anehana's interactive availability idea.
  2. Adapted for VSS: the hero is a flagged concept render (no real project photography is hero-grade yet); the interactive 24-plot site plan is the page's product moment, feeding a sticky navy detail panel (plot no, status, area, price, facing, "Reserve for a site visit"); the gallery uses only real VSS site photographs with caption chips; the verification section anchors on the actual signboard photo; the fixed image is the shared brand render — it is never captioned as the project.
  3. Improves on the previous proposal: replaces the stacked info-blocks page with a single continuous "walk-through" scroll; the plot map is now a first-class interactive product feature instead of a static image; facts band, ghost typography and full-bleed moments create dense↔sparse rhythm; every unverifiable figure is visibly flagged instead of silently invented.
  4. Client to supply: real hero-grade project photography; confirmed site plan geometry/dimensions/orientation; per-plot areas, prices & statuses; DTCP approval number; landmark names & distances; gallery captions; story copy.
